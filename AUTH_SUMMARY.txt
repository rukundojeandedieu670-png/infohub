🗄️ DATABASE CHANGES
═══════════════════════════════════════════════════════════════════════════

NEW TABLE: password_reset_tokens

  Columns:
  ├─ id (INT, auto-increment, primary key)
  ├─ user_id (INT, foreign key → users)
  ├─ token (VARCHAR 255, UNIQUE, plain token URL param)
  ├─ token_hash (VARCHAR 255, SHA-256 hash, never plain)
  ├─ expires_at (TIMESTAMP, 1 hour from creation)
  ├─ used_at (TIMESTAMP NULL, marks one-time use)
  ├─ ip_address (VARCHAR 45, IPv4/IPv6)
  ├─ user_agent (VARCHAR 500, browser info)
  └─ created_at (TIMESTAMP, default NOW())

  Indexes:
  ├─ PRIMARY KEY (id)
  ├─ idx_user_id (performance on user lookups)
  ├─ idx_token_hash (O(1) token verification)
  ├─ idx_expires_at (cleanup expired tokens)
  └─ idx_used_at (find unused tokens)
